J I J I N G / THE JADE BETWEEN

Every person's boundaries.
The same weight.

Jijing brings negotiation into a shared, bounded space. Independent AI executions compile natural-language conditions into rules. Code enumerates every option and, when no plan works, lists every inclusion-minimal conflict and withdrawal set with concrete witnesses.

Only the owner can withdraw a condition. There is no automatically chosen best plan. The protocol commits only when every member approves the same plan at the same revision.

Exhaustive proofs apply to the accepted formal rules and bounded domain. They do not prove that AI understood the conditions correctly or enforce real-world performance. Unexpressible conditions require review; cancel and recreate the session.
