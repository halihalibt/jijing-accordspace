# V4 — three ascensions and an unreasonable second world

The user rejected V3's gentle glide and requested escalating sword forms,
stronger attacks and an automatic, absurd world transition after three echoes.

The three echoes now upgrade sword geometry and flight/trail behavior by count:
1. Snowsoul / Twin Fangs: forked jade silhouette, dual ribbons and heavier dash.
2. Moonwheel / Orbital Blades: a circular guard, orbiting swords, layered trails.
3. The Cosmic Megasword: an oversized cosmic form and automatic cutscene.

Normal entry now anticipates for 230 ms, accelerates with a power curve, hits a
shock ring and recoils. The final sequence charges, winds up a 150vh sword,
slashes across the gate, holds the hit for 170 ms, shakes the landscape, tears
13 texture fragments apart and travels through a tunnel into the second world.
It lasts about 4.8 seconds. A skip control is available; reduced motion shortens
the sequence and omits shake, trails and fragments. Background tabs pause scene
time instead of queuing impact effects. Return cancels the sequence and resets
collection and sword level. Repeated echoes cannot trigger multiple cutscenes.

The second world uses an actual generated scene, `assets/inverted-star-sea.webp`:
a jade cosmic whale, a fractured ringed moon, inverted pagodas and impossible
waterfalls. Its full final prompt and generation provenance are in
`assets/INVERTED_STAR_SEA_PROMPT.md`. The built-in image generation tool produced
the original PNG; the web asset keeps its 1672×941 dimensions with WebP encoding.
The original jade scene and canonical intelligent contract remain unchanged.

Second-world controls invert gravity in 180-degree steps, summon animated sword
rain, and return to the original world. These are local scene interactions and
never alter negotiated conditions, arm wallets or call the blockchain. Existing
live wallet budgets, no-resend protections and offline tutorial remain intact.

17 assertion groups evaluate the actual served browser bundles in a browser-like
DOM, including four distinct forms, all cutscene phases, automatic world change,
repeat-trigger protection, second-world controls, replay/reset, skip and reduced
motion, plus the existing complete negotiation and wallet checks. Canvas is
stubbed: this is not a real WebGL render, pixel-level visual check or audio test.
The supported managed preview browser is unavailable; device visual/audio
acceptance remains open. No chain transaction or signature was performed.
