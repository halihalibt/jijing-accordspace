# 霁境 · Jijing / AccordSpace

An ice-jade spatial experience for shared-plan negotiation on GenLayer.

Jijing places a small group inside an ice-jade sanctuary where their own conditions become a shared, inspectable planning state. The product combines an atmospheric spatial interface with a real Stable Studionet execution path for AccordSpace.

## Live experience

Open the workspace to explore the ice-jade scene. The interface includes WebGL displacement, touch ripples, drag/hold transitions, sculpted jade typography, sword-flight entry, three replayable jade echoes, a cosmic second world, gravity inversion, sword rain, and user-enabled continuous Web Audio ambience.

The product is bilingual (EN / 中文), responsive, and does not require a wallet for its tutorial.

## Why the contract matters

AccordSpace is not a generic AI verdict. It combines independent semantic compilation with deterministic finite-domain solving, exhaustive inclusion-minimal conflict/correction witnesses, owner-only relaxation, revisioned approvals, and unanimous commitment.

The formal domain is deliberately bounded. The protocol does not claim to enforce external events or real-world behavior outside that domain.

## Tutorial and product behavior

The no-wallet tutorial demonstrates a three-person contradiction and lets the visitor inspect its conflict/correction structure before resolving it through an owner-only waiver and unanimous approval.

The real-session interface exposes wallet-signed calls only for the actual deployed contract. Account or network changes invalidate authorization, and the client never uses private keys or background signers.
